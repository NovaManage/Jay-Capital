JAY CAPITAL FUNDING — ILLUSTRATOR MASTER FILE

  jcf-brand-master.svg   One 2400 x 3000 px artboard: every lockup, every
                         monogram variant, and the full palette with hex /
                         RGB / PMS callouts.

OPENING IN ILLUSTRATOR
  File > Open > jcf-brand-master.svg
  Illustrator imports SVG natively as live vector — no tracing, no rasterizing.
  Every element is an editable path.

SAVING AS A TRUE .AI
  With the file open: File > Save As > Adobe Illustrator (*.AI).
  That gives you jcf-brand-master.ai as your working master. (An .ai cannot be
  generated outside Illustrator, which is why the vector master ships as SVG —
  it is the same artwork, losslessly.)

LAYER / GROUP STRUCTURE
  Illustrator reads each group id as a named group in the Layers panel:
    Lockup-Primary-Stacked        Lockup-Stacked-Reverse
    Lockup-Horizontal             Lockup-Horizontal-Reverse
    Lockup-One-Color-Navy         Lockup-One-Color-White
    Monogram-Gradient             Monogram-Flat-Gold
    Monogram-Navy                 Monogram-White
    Color-Swatches                Type-Notes    Sheet-Title
  Delete the groups you don't need, then File > Export for a clean single asset.

BEFORE SENDING TO A VENDOR
  The wordmark is LIVE TEXT in Cinzel. Select it and run
  Type > Create Outlines (Shift+Cmd+O) so the vendor needs no fonts.
  The monogram is already outlined paths.

GRADIENT
  Linear, 45 degrees, light at the upper right:
  #E8C583 -> #C0954A (42%) -> #9C6E26
  For foil, spot, or embroidery use jcf-mark-flat-gold.svg instead.
